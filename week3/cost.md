"시행 1개 판정": 구성 A는 윈도우 19개를 예측한 뒤 다수결하는 시간, B · C는 표본 1개 = 시행 1개라 추론 시간과 같다.

RF를 학습한 뒤 n_jobs=1 로만 바꿔 표본 1개씩 100회 예측: 구성 A 7.281 ms, 구성 B 6.943 ms, 구성 C 7.461 ms. n_jobs=-1 과의 차이가 표본 1개마다 CPU 여러 개에 일을 나눠 주는 준비 시간이고, n_jobs=1 에서도 남는 시간은 트리 100개를 하나씩 호출하는 비용이다. 묶음 추론에서는 이 고정 비용이 표본 수로 나뉘어 작아진다.

특징 추출 (2초 구간 1개 → 윈도우 19개 x 25차원, 2주차 td_features): **1.851 ms / 시행** (200시행 평균)
