# 설정 근거 (제출물 ⑥)

## 윈도우 200 ms 를 고른 이유

논문이 쓴 분석 창 길이이고, 1 kHz에서 200샘플이면 RMS · ZC 같은 통계량을 한 창 안에서 계산하기에 표본이 충분하다. 동작 수행이 1초뿐이라 창이 이보다 길면 동작과 휴식이 한 창에 섞이고 판단도 그만큼 늦어지며, 반대로 100 ms로 줄이면 지금도 창당 평균 2.9\~12.1회인 ZC 같은 횟수 특징이 절반쯤으로 작아져 값이 거칠어진다.

## 오버랩 50% 를 고른 이유

논문 설정(증분 100 ms)이고, 겹치지 않게 자르면 2초에서 10개뿐인 창이 19개로 늘어 학습 표본이 약 두 배가 되며 창 경계에 걸린 동작의 시작 · 끝도 다음 창의 한가운데에서 한 번 더 잡힌다. 75%로 더 겹치면 창은 37개가 되지만 이웃 창의 3/4이 같은 신호라 새 정보는 거의 늘지 않고 계산량과 표본 사이의 상관만 커지므로 50%를 절충점으로 봤다.

- 창 개수 계산: (2000 − 200) / 100 + 1 = 19 (0% → 10개, 50% → 19개, 75% → 37개)
- 겹친 창은 서로 독립이 아니다. 그래서 반드시 시행 단위로 먼저 나눈 뒤 창을 만든다(`step5_dataset.py`).

## 시간영역 특징만 쓴 이유와 포기한 것 (본 강의자료 29쪽)

논문이 든 근거는 시간영역 특징이 빠르게 계산되고 견고하며, EMG 동작 인식에서 널리 검증됐고, 경량 · 계산 효율이라는 연구 목표에 맞는다는 것이다. 대신 주파수영역 특징(MNF · MDF)과 시간–주파수 특징(웨이블릿 계수)은 계산 복잡도 때문에 쓰지 않았다.

포기한 것의 영향은 각도 구분에서 나타날 수 있다. 논문은 같은 동작의 서로 다른 각도 사이의 혼동을 주요 오류로 설명하고, 시간영역 특징이 두 각도의 미세한 근활성 차이에 덜 민감할 수 있다고 해석한다. 주파수 · 시간–주파수 특징 추가는 논문이 제안한 향후 개선 방향이므로 이번 주에는 넣지 않았다.

## 그 밖의 설정 — 논문 조건과 실습(재현) 가정 구분

| 항목 | 값 | 출처 |
|---|---|---|
| 노치 필터 | 60 Hz | 논문 |
| 대역통과 | 20\~450 Hz Butterworth 4차 | 논문 |
| 노치 Q | 30 | 실습 설정 (논문에 없음) |
| 필터 적용 방식 | filtfilt (영위상), 시행으로 자르기 전 연속 기록에 적용 | 실습 설정 |
| 세그먼트 길이 | 2초 (2,000샘플) | 논문 |
| 세그먼트 시작점 | mark + 0.5초 (0.5\~2.5초) | **재현 가정** — 논문 미명시, `segment_start.md` 의 비교로 정함 |
| 윈도우 · 증분 | 200 ms · 100 ms (19개) | 논문 |
| 특징 | RMS · MAV · WL · ZC(th = 0.01) · SSC × 5채널 = 25차원 | 논문 식 (1)\~(5) |
| 모델 입력 표본 | 윈도우 1개 = 표본 1개 (시행당 19개) | 실습 예시 — 논문은 세부 방식 미명시 |
| 분할 | 시행 단위 8:2, random_state = 42, 층화 = 피험자 × 클래스 | 논문(시행 단위 8:2) + 실습 설정(층화 기준 · 시드) |
| 표준화 | StandardScaler, 학습셋에서만 fit | 논문(StandardScaler) + 실습 권고(fit 범위) |

### 세그먼트 시작점을 0.5초로 둔 이유

프로토콜은 휴식 2초 → 동작 1초 → 휴식 2초지만, 1주차에 확인했듯이 이 데이터의 근활성은 mark 뒤 약 1\~2.5초에 나타난다. 시작점 후보를 0.25초 간격으로 바꿔 가며 "시행마다 근활성이 가장 큰 1초"가 2초 구간 안에 통째로 들어오는 시행 비율을 세면 0.5초에서 86.8%로 가장 높고, 슬라이드 예시 값인 1.5초에서는 6.6%에 그친다(`segment_start.md`). 이 기준은 라벨을 쓰지 않으므로 테스트 정보를 미리 본 것이 아니다.

### ZC 임계값 0.01 에 대해

이 데이터에서 인접 샘플 차이의 크기는 예시 세그먼트 기준 채널별 중앙값 0.0011\~0.0095로, 임계값 0.01보다 작은 경우가 많다. 그래서 th = 0.01을 쓰면 ZC가 th = 0일 때보다 크게 줄고(예시: ECR 26.8 → 10.2, Biceps 20.9 → 1.2, Triceps 25.5 → 0.1), 신호가 작은 채널에서는 0에 가까워진다. 전체 학습셋에서도 ZC 평균은 Triceps 2.95회 · Biceps 4.51회로 전완 채널(6.76\~12.11회)보다 작고, Triceps는 윈도우의 48%에서 ZC가 0이다. 논문 식 (4)를 따르기 위해 0.01을 유지하되, ZC가 "주파수 지표"라기보다 "큰 진폭으로 0을 지나는 횟수"에 가깝게 동작한다는 점을 기록해 둔다(`feature_order.md`).
